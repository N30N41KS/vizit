# Персональный сайт-визитка с AI-ассистентом

Интерактивный сайт-портфолио с динамическими эффектами, анимациями и интеграцией нейросетевого ассистента.

## Особенности
* Адаптивный фронтенд с визуальными эффектами и анимацией.
* Бэкенд на Node.js с подключением Google Gemini API для генерации ответов посетителям.
* Система триггеров: отслеживание ключевых слов в диалоге и уведомление владельца.
* Панель администратора для просмотра сессий и истории диалогов.

## Стек
* JavaScript (ES6+), HTML5, CSS3
* Node.js
* Google Gemini API

## Запуск
1. Клонировать репозиторий:
   git clone git@github.com:N30N41KS/vizit.git
   cd vizit
2. Установить зависимости:
   npm install
3. Запустить сервер:
   node index.js
